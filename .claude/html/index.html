§2 Schedulers

All \Edge-Radar\ Windows Task Scheduler tasks. Times in PT (system local).
# Task Cadence Trigger What it does
1 Daily-Summary daily 4:50 AM Morning P&L digest — yesterday settled + open exposure + today pending + 7d rolling. Output: reports/Performance/daily_summary_*.md
2 Email-Daily-Summary daily 5:00 AM Emails the daily-summary report to mikeschecht@gmail.com. Subject: Edge-Radar | Daily Summary
3 All-Sports-SameDay-Execution daily 5:05 AM Scans NBA/NHL/MLB/NFL for today's games and places bets. --date today --budget 15% --max-bets 7 --exclude-open
4 All-Sports-NoDateFilter-Execution Mon · Thu 5:20 AM Scans all sports across all dates for multi-day edge. --budget 15% --max-bets 6 --exclude-open (no --date)
5 Email-SameDay daily 5:25 AM Emails today's same-day execution report. Empty-day emails still fire (proof-of-life pattern)
6 Email-NoDateFilter Mon · Thu 5:40 AM Emails the weekly-broad execution report. 20-min buffer after the 5:20 execute
7 NextDay-Execute Sun-Thu 6:00 PM Locks in early lines for tomorrow's games. --date tomorrow --budget 10% --max-bets 6 --exclude-open
8 Email-NextDay Sun-Thu 6:20 PM Emails the next-day execution report
9 Calibration Sun 7:00 PM Weekly Brier-score refresh + calibration curve. model_calibration.py --days 7 --save
10 Backtest Sun 7:30 PM Weekly equity curve, drawdown, Sharpe, strategy comparison. backtester.py --simulate --save
11 NightlySettle daily 11:00 PM Fetches settlement data from Kalshi, updates trade log, calculates realized P&L
12 Reconcile daily 11:30 PM Diffs local trade log against Kalshi API positions; flags drift. 30-min buffer after settle
13 Weekly-Analysis Sun 11:45 PM End-of-week 7-day betting_analysis.py — headline, by sport/category/side/edge/conf, calibration, longshots, streaks, ledger
14 Email-Weekly-Analysis Sun 11:55 PM Emails the weekly performance analysis report
15 MonthlyCalibration monthly 1st · 2:00 AM 30-day Brier refresh. model_calibration.py --days 30 --save. Catches slow calibration drift
16 U2-Review one-shot 2026-05-14 7:00 AM Post-ship review of U2 daily-summary digest (~2 weeks after 2026-04-30 ship). Firing-reliability + section coverage + code review
17 R8-Review one-shot 2026-05-29 6:00 AM R8 cross-category dedup A/B review (~30 days post-ship). Slices ML/Total/Spread same-game cohorts; recommends per-sport CROSS_CATEGORY_DEDUP_<SPORT> flips

Manual trigger commands (Git Bash) 
# Prepend MSYS_NO_PATHCONV=1 to stop Git Bash from translating /tn
MSYS_NO_PATHCONV=1 schtasks /run /tn "\Edge-Radar\Daily-Summary"
MSYS_NO_PATHCONV=1 schtasks /run /tn "\Edge-Radar\All-Sports-SameDay-Execution"
MSYS_NO_PATHCONV=1 schtasks /run /tn "\Edge-Radar\NextDay-Execute"
MSYS_NO_PATHCONV=1 schtasks /run /tn "\Edge-Radar\NightlySettle"
MSYS_NO_PATHCONV=1 schtasks /run /tn "\Edge-Radar\Reconcile"
MSYS_NO_PATHCONV=1 schtasks /run /tn "\Edge-Radar\Calibration"
MSYS_NO_PATHCONV=1 schtasks /run /tn "\Edge-Radar\Weekly-Analysis"

# PowerShell equivalent (no MSYS prefix)
Start-ScheduledTask -TaskPath '\Edge-Radar\' -TaskName 'NextDay-Execute'

# List + next run + last result
Get-ScheduledTask -TaskPath '\Edge-Radar\' | ForEach-Object {
  $info = Get-ScheduledTaskInfo -TaskName $_.TaskName -TaskPath $_.TaskPath
  [PSCustomObject]@{
    Name = $_.TaskName; State = $_.State
    NextRun = $info.NextRunTime; LastRun = $info.LastRunTime
    LastResult = $info.LastTaskResult  # 0 = success
  }
} | Sort-Object NextRun | Format-Table -AutoSize
