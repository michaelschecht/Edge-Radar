# Edge-Radar Icon Proposals

Square Edge-Radar icon proposals for favicons, app icons, and clickable buttons.

Open [`../preview.html`](../preview.html) to compare these icons alongside the landscape logo proposals.

## Dark Icons

- [Market Sweep](./dark/favicon-01-market-sweep.svg) - radar sweep finding live market edges.
- [Fair Value Curve](./dark/favicon-02-fair-value-curve.svg) - fair-value curve compared with market price.
- [Risk Gate](./dark/favicon-03-risk-gate.svg) - risk gates clearing a candidate opportunity.

## Light Icons

- [Market Sweep Light](./light/favicon-01-market-sweep-light.svg) - light version of the radar sweep concept.
- [Fair Value Curve Light](./light/favicon-02-fair-value-curve-light.svg) - light version of the fair-value comparison concept.
- [Risk Gate Light](./light/favicon-03-risk-gate-light.svg) - light version of the risk-gate concept.

## Notes

- All links are relative to this README, so they keep working if the entire `Edge-Radar-Images/` folder is moved.
- Icon assets use a `256 x 256` viewBox and are safe for square favicon export.
- SVG format keeps the marks crisp for browser favicons, toolbar buttons, app tiles, and README badges.
